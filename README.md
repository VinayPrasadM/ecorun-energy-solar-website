# Ecorun Energy: Solar Lead-Generation Website

> **Case study.** This is client work, so the source code stays private to the client. This repo documents what I built and how.

![Ecorun Energy website](https://framerusercontent.com/images/VUri0blqoR6oawClO1PEQjYYU0s.png)

**Live:** [ecorun.energy](https://ecorun.energy/) · **Client:** Ecorun Energy, Pakenham, Victoria, Australia · **Role:** Custom development, local SEO and copywriting

## The brief

Ecorun Energy is a CEC-accredited solar installer in Pakenham, Victoria. They needed a fast website that turns local searches into quote requests.

## What I built

A custom-coded lead-generation website with no page builder.

- The hero leads with a free-quote call to action and a rebate eligibility check
- Residential and commercial service sections, a step-by-step process, reviews and FAQs
- Mobile-first, so visitors can call or request a quote in one tap
- Local SEO targeting solar searches in Pakenham, with a page title and meta description written for Google

## Tech

| Layer | Stack |
| --- | --- |
| Front-end | Tailwind CSS, JavaScript |
| Build | Vite, for a lightweight, fast-loading bundle |
| SEO | Local SEO, custom title and meta description |
